# Architecture & Walkthrough

The legacy stat-arb strategy has been fully deprecated and removed from the active repository. The codebase has transitioned entirely to the new tick-based ML **Opportunity Cost Optimization (OCO)** architecture.

All execution and orchestration logic moving forward will rely entirely on the rolling offline artifacts generated by the ML pipeline (e.g., `_oco_live_lock.json`, `_oco_allowed_states.csv`). Run `make docs` to view the comprehensive OCO System Reference built dynamically from the governance pipeline.
