# API Parity Failure Fix Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Re-run the WFO/ML pipeline for all six symbols via `make retrain-all` so that predictions parquets and model threshold JSONs are generated together and are in sync, then re-run `make freeze-oco` to produce valid governance lock files.

**Architecture:** `make freeze-oco` runs `validate_api_parity.py` before freezing. That script compares the `selected_exec` column in the predictions parquet against what the model JSON's daily thresholds would choose — and found 370 EURUSD rows where the backtester selected candidates that the current threshold rejects. The predictions parquet and model JSON got out of sync because a model recalibration updated the threshold JSON without also regenerating the predictions. The fix is `make retrain-all`, which runs `onboard_symbol.py --skip-data` for all six symbols, producing both new model files and new prediction parquets in the same pipeline pass. By construction the two are then in sync. `make freeze-oco` follows immediately after.

**Tech Stack:** `make`, `uv`, Python — `scripts/onboard_symbol.py`, `scripts/validate_api_parity.py`, `scripts/freeze_oco_live_governance.py`, `scripts/validate_oco_live_governance.py`

## Execution Rules

- Do not manually edit model files, threshold JSONs, or parquet files. The pipeline generates them.
- Do not skip `make retrain-all`. The parity failure cannot be resolved by patching the freeze target or adjusting tolerance — the underlying data must be regenerated.
- `make retrain-all` takes a long time (runs WFO for all 6 symbols). Set a timeout of at least 60 minutes. Do not interrupt it partway through a symbol.
- If a single symbol fails during `retrain-all`, stop and report BLOCKED. Do not try to run the remaining symbols manually.
- If parity still fails after `retrain-all`, that is a deeper model/pipeline issue — stop and escalate.
- Do not commit model files or parquet files — they are gitignored.
- The only commit in this plan is the six updated `_oco_live_lock.json` files.

- [ ] **Step 2: Run inline Python hash check across all six symbols**

```bash
cd /Users/danielfisher/repositories/behemoth && UV_CACHE_DIR=.uv_cache uv run python - <<'PY'
import hashlib, json
from pathlib import Path

def sha256(p: Path) -> str:
    h = hashlib.sha256()
    with p.open("rb") as f:
        for chunk in iter(lambda: f.read(1024 * 1024), b""):
            h.update(chunk)
    return h.hexdigest()

symbols = ["audusd", "eurusd", "gbpusd", "usdcad", "usdchf", "usdjpy"]
all_ok = True
for sym in symbols:
    lock = json.loads(Path(f"configs/research/governance/oco/{sym}_oco_live_lock.json").read_text())
    arts = lock.get("artifacts", {})
    cbm_path = Path(arts["model_cbm_path"])
    thr_path = Path(arts["model_threshold_json_path"])
    cbm_ok = sha256(cbm_path) == arts["model_cbm_sha256"]
    thr_ok = sha256(thr_path) == arts["model_threshold_json_sha256"]
    status = "OK" if (cbm_ok and thr_ok) else f"FAIL cbm={cbm_ok} thr={thr_ok}"
    print(f"{sym.upper()}: {status}")
    if not (cbm_ok and thr_ok):
        all_ok = False

print()
print("ALL PASS" if all_ok else "FAILURES DETECTED")
PY
```

Expected: each symbol prints `OK` and the final line is `ALL PASS`.
